## Why the change?

We rebranded from **AI Security Gateway** to **Occludra** to give the project a distinct, ownable name. Everything you know is still here — just under the new name:

- **Same open-source core** — Apache 2.0, Docker, self-hostable.
- **Same drop-in AI firewall** — redacts PII, blocks prompt injection, enforces budgets, and now includes an **MCP Gateway** for securing agent tool calls (private beta).
- **Same company** — operated by Datum Fuse LLC.
